# Badusb scripts
repository of all the Bad usb scripts i made
This repsitory is not finished (it probably never will be) so there may be a very small ammount of scripts
I am not the best at making these tools so expect these to be the worst ones you have ever seen
Bad usb scripts (or rubber ducky scrips) are a .txt file that can control a computer with an external device like a flipper zero or a LILYGO T- Dongle S3

below is the list and info about the current ones i made

1. Tabcloser (flipper zero version): a simple badusb script that presses ALT+F4 every 100 milliseconds 15 times
2. Tabcloser (Rubber Ducky version): same thing as the flipper zeros one except there are Ducky 3.0 functions (open the file and modify the settings to your liking before using)
